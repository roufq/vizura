# Vizura POS

## Ringkasan
Aplikasi POS multi-lokasi untuk UMKM dengan manajemen stok, pembelian, penjualan, dan laporan keuangan dasar.

## Fitur Utama
- Autentikasi pengguna, manajemen profil, dan verifikasi email.
- Manajemen peran dan pengguna (Owner, Manager, Kepala Toko, Kasir).
- Lokasi multi-cabang dengan pemilihan lokasi aktif.
- Master data produk, kategori, satuan, dan pemasok.
- Produk mendukung SKU dan barcode.
- POS cepat: transaksi penjualan, draft vs post, diskon baris/order, pajak inklusif/eksklusif.
- Pembayaran multi-metode, termasuk piutang dan pengelolaan pelunasan.
- Scan barcode di web app: scanner HID langsung menambah item/qty tanpa trigger tambahan.
- Void dan retur penjualan dengan pembaruan stok otomatis.
- Pembelian barang dan pengelolaan hutang pembelian.
- Penyesuaian stok dengan proses approval.
- Transfer stok antar lokasi (kirim/terima).
- Biaya operasional dan pencatatan jurnal otomatis.
- Audit log aktivitas transaksi penting.

## Laporan
- Laporan penjualan (filter tanggal, kasir, metode bayar, status).
- Laporan kas harian (cash-up).
- Laporan stok per lokasi dan konsolidasi.
- Kartu stok (pergerakan stok per produk).
- Laporan laba rugi.
- Laporan arus kas.

## Dashboard
- Ringkasan penjualan hari ini/bulan ini.
- Jumlah transaksi harian.
- Produk aktif dan stok menipis.
- Top produk terjual.
- Penyesuaian stok terbaru.
